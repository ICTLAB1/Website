#
# Uploaded at https://search.google.com/search-console/disavow-links — one file

# whole list and not an addition to it.

# ---------------------------------------------------------------------------
# Why this exists
# ---------------------------------------------------------------------------
#
# On 2026-10-11 a backlink index reported 1023 referring domains for this
# site. Of the 1000 it would return in one page, 967 scored 40 or worse for
# spam and not one scored above 10 for authority. The anchor text says what
# they are:
#
#   "Premium Backlink Services techzoidtechnologies.com for Stronger Google
#    Rankings"                                    943 links / 931 domains
#
#   "High Quality Dofollow Backlinks DA 50 PA 40 Premium PBN Network Service
#    techzoidtechnologies.com Rank First Page Google Fast SEO Link Building
#    Buy Backlinks Online Cheap"                   17 links /  17 domains
#
# Nobody writing about a software reseller produces that sentence. It is the
# footprint of a private blog network, and the domains carry it: 967 of them
# across .website, .store, .site, .shop, .online and .space, almost all
# registered to serve exactly this.
#
# It is also still happening. New referring domains per day:
#
#   2026-09-28   22
#   2026-09-29   37
#   2026-09-30   29
#   2026-10-01   36
#   2026-10-02   29
#   2026-10-03   70
#   2026-10-04   82
#   2026-10-05   90
#   2026-10-06   82
#   2026-10-07   82
#   2026-10-08   89
#   2026-10-09   81
#   2026-10-10   89
#   2026-10-11   58
#
# ---------------------------------------------------------------------------
# What this file does and does not do
# ---------------------------------------------------------------------------
#
# Google states it already ignores links like these, and that a disavow file is
# mainly for a site under a manual action. So this is unlikely to move a
# ranking on its own, and it should not be uploaded in the expectation that it
# will. It is worth uploading anyway for two reasons: if there is a manual
# action against this site, the disavow is a required part of answering it; and
# if the links are ever counted, they are counted against a brand name, which
# is the one anchor a business cannot afford to have attached to
# "buy backlinks online cheap".
#
# The thing that actually matters is upstream of this file: find out where
# these links came from. If somebody bought an SEO package, cancel it — the
# file will never catch up with a supplier adding ninety domains a day. If it
# is a competitor, this is the response and there is nothing else to do.
#
# Check Search Console → Security & Manual Actions → Manual actions before
# assuming either.
#
# ---------------------------------------------------------------------------
# Scope
# ---------------------------------------------------------------------------
#
# Domain-level (`domain:`) rather than per-URL, because the whole site is the
# problem in every case here and a PBN rotates its paths.
#
# Covers 967 of the 1023 domains the index reports: one page is 1000 rows and
# 33 of those were clean. Re-export and regenerate when the attack stops, or
# periodically while it continues — see seo/README.md.
