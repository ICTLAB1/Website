## Rule applied

**301** where this site has a page that answers the question the old URL asked — the same
product in the catalogue, or a topic page that states the answer outright. `/autocad` says
AutoCAD LT was consolidated into the main AutoCAD line, so both LT URLs redirect there.

**410** everywhere else. A brand page is not a replacement for a product page; it is a
consolation, and Google scores a redirect to one as a soft 404 — which is what put six of these
into a Merchant Center report while they looked, from the outside, like working redirects.

410 rather than 404: 404 means "ask again some time", and a crawler will, for months.
410 means gone, and search engines drop the URL far faster for it.

## What this cost

Retiring these discards link equity and search positions that were measured on 23 August 2026:

| URL | What it carried |
|---|---|
| `/product-page/microsoft-visual-studio-enterprise` | position 13, 8,100 searches/month |
| `/product-page/microsoft-visio-plan-1` | position 10, 720 searches/month |
| `/product-page/autodesk-vault-business-license` | 3 inbound links |
| `/product-page/3ds-max-business-license` | 3 inbound links |
| `/product-page/microsoft-365-apps-for-business-annual-subscription` | 3 inbound links |

That is 9 inbound links and 2 ranking positions, given up deliberately. Each is reversible by
adding a redirect back to `next.config.ts` — but only worth doing if the product is listed, since
sending it to a brand page is what caused this.

## Retired prefixes

An unlisted URL under any of these is 410, so nothing falls through to a listing page:

`/product-page/` · `/service-page/` · `/blog/categories/` · `/post/` · `/shop-1`

Handled in `src/proxy.ts`. Redirects in `next.config.ts` run first, so a listed URL still
redirects; only what no rule claims reaches the 410.
